# Краткое описание, что хочу сделать
Изучив как парсятся md файлы,
решил делать это через AST(абстрактное синтакисческое дерево)
разделил логику на 4 слоя. 
1. В первом хранятся абстракции (Abstractions)
2. Во втором конкретные элементы (MDNodes)
3. Слой с логикой парсинга (MdParser)
4. Вход для пользователя (Md)

Разделил все спец символы на группы 
Получились "парные" и "не парные" группы. 
Сделал для парных отдельный абстрактный класс, 
для "не парных" не делал
