# Структура проекта
## Md
Md - просто интерфейс между логикой и использованием извне. Просто запускает парс, передавая текст 

## MarkdownParser
Проверяет на валидность полученный текст, делит на строки, передает строки в инлайн парсер, соединяет обратно уже в html разметку (Просто соединяет, а не переводит)

## InlineParser
Проходится посимвольно по строке line, проверяя на наличие тегов. При их наличии меняет markdown-символы на html-разметку. Список проверяемых тегов хранит в словаре.

### TagInfo
Вспомогательный для InlineParser класс, хранит взаимосвязь markdown-html
