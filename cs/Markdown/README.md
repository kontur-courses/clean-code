### Структура проекта и взаимодействие компонентов:

Проект разделен на три независимых уровня по принципу единственной ответственности (SRP)

1. Шаг выделения блоков (Blocks):
Md.cs - точка входа. Пользователь вызывает Md.Render.
BlockParser.cs - парсер блочного уровня. Читает входной текст, определяет, к какому типу относится строка (заголовок или обычный абзац), и возвращает список моделей Block.
Block.cs, HeadingBlock.cs, ParagraphBlock.cs — модели данных. Они просто хранят текст.

2. Шаг выделения тегов внутри блоков (Inline):
InlineParser.cs - парсер строчного уровня. Отвечает за поиск тегов ('_', '__', '[]()') внутри текста и возвращает список моделей InlineTag.
InlineTag.cs, TextTag.cs, ItalicTag.cs, StrongTag.cs, LinkTag.cs - модели инлайн-тегов. Хранят текст и параметры (например, URL для ссылки).

3. Шаг рендеринга (Renderer):
HtmlRenderer.cs - класс, который умеет генерировать HTML. Принимает список блоков и инлайн-тегов и оборачивает их в HTML-теги.
